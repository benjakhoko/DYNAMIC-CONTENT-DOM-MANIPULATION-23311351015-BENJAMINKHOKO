## Description

## Description

The Document Object Model (DOM) is a programming interface that represents an HTML document as a hierarchical tree of nodes, where each element, attribute, and piece of text is treated as an object that can be accessed and manipulated using JavaScript. Through DOM manipulation, developers can dynamically create, read, update, and delete content on a web page without requiring the browser to reload the entire page. This project demonstrates the concept of Dynamic Content (DOM Manipulation) through an interactive Quiz Application designed to showcase how JavaScript interacts with the DOM in real time. The application utilizes important DOM methods and properties such as `getElementById()`, `querySelector()`, `createElement()`, `appendChild()`, `textContent`, `innerHTML`, and Event Listeners. Users can answer questions, receive immediate feedback, and track their scores as the application updates the page dynamically. Addition, a live DOM operations log visually illustrates create, read, update, and delete (CRUD) actions, providing a practical demonstration of how modern interactive web applications function.

## How to Run the Demo

### Method 1: Open Directly in Browser

1. Download or extract the project folder.
2. Open the project folder.
3. Double-click `index.html`.
4. The Quiz Application will open in your default web browser.

### Method 2: Using Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The application will launch in your browser.

## How the Demo Works

1. Questions are dynamically created using `createElement()`.
2. Elements are inserted into the page using `appendChild()`.
3. User answers are processed through Event Listeners.
4. The score counter is updated using `textContent`.
5. Previous questions are removed using `innerHTML`.
6. A DOM Operations Log displays CREATE, UPDATE, and DELETE actions in real time.
